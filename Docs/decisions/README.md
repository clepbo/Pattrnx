# Architecture Decision Records

Decisions made at kickoff are recorded in `ARCHITECTURE.md` §18 (TD-1 … TD-13).
Record any later architectural decision here as `NNNN-short-title.md`, numbered
from `0001`:

```markdown
# NNNN — Title

- Status: proposed | accepted | superseded by NNNN
- Date: YYYY-MM-DD

## Context
## Decision
## Alternatives considered
## Consequences
```

After an ADR is accepted, update `ARCHITECTURE.md`, and `ARCHITECTURE_ESSENTIALS.md` if it's affected.
